# Sistema Orcose

Sistema web desenvolvido para gerenciamento de informações de um escritório de contabilidade.

## Sobre o projeto

O Sistema Orcose foi desenvolvido como projeto acadêmico com o objetivo de centralizar informações e facilitar o gerenciamento de empresas, pessoas e usuários.

A aplicação integra frontend, backend e banco de dados, permitindo a realização de operações de cadastro, consulta, edição e exclusão de informações.

## Tecnologias utilizadas

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express.js
- API REST

### Banco de dados

- MySQL
- MySQL Workbench

### Ferramentas

- Visual Studio Code
- Git
- GitHub

## Funcionalidades

- Autenticação de usuários
- Controle de acesso por tipo de usuário
- Cadastro de empresas
- Cadastro de pessoas físicas
- Gerenciamento de usuários
- Operações CRUD
- Integração com banco de dados MySQL
- Processamento de arquivos XML
- Notificações na interface
- Modo escuro
- Exportação de dados
